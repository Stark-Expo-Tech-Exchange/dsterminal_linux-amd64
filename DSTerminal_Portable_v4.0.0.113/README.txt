DSTERMINAL PORTABLE v4.0.0.113
========================================

This is the portable version of DSTERMINAL.

HOW TO USE:
1. Double-click launch_dsterminal.bat
2. Wait for the server to start
3. Open http://localhost:5000 in your browser
4. The dashboard will load automatically

SYSTEM REQUIREMENTS:
- Windows 10 or later
- 4GB RAM recommended
- 200MB free disk space

FEATURES:
- Web-based dashboard
- Real-time monitoring
- Auto-quarantine
- MITRE ATT&CK integration
- Customizable settings

NOTES:
- No installation required
- No admin privileges needed (except for some security features)
- All data is saved in: %APPDATA%\DSTerminal\workspace
- This is a network service - keep the terminal window open

TROUBLESHOOTING:
- If the dashboard doesn't open, check the terminal window for errors
- Make sure port 5000 is not in use
- Try running as administrator for full features
