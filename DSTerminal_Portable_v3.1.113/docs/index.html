1. Introduction to DSTerminal

DSTerminal v3.1.113 is a comprehensive Security Operations Center (SOC) platform designed for defensive security professionals. It provides a unified terminal interface for threat detection, incident response, forensics, system hardening, and network intelligence operations.

  • • SOC Nmap Dashboard - Interactive 3-panel network intelligence with AI vulnerability scoring
  • • Real-time Network Monitoring - Live threat detection with geolocation and risk scoring

  • • Ransomware Protection - Real-time monitoring with auto-quarantine and restore
  • • 10-Pillar System Hardening - Comprehensive security hardening framework
  • • Multi-format Reporting - JSON, HTML, PDF with dark-themed dashboards
  • • Professional Windows Installer - Inno Setup-based deployment with dependency management

3. Installation Guide

3.1 Windows Installation (Recommended)

# DSTerminal Windows Installer
1. Download DSTerminal_Installer_2026_v3.1.13.exe from GitHub
2. Run the installer (no administrator rights required)
3. Follow the setup wizard to choose installation options
4. Select components: Core, Documentation, Tools, Dependencies
5. Dependencies will be auto-installed from bundled files:
   - Npcap (packet capture)
   - Nmap (network scanner)
   - SQLMap (SQL injection)
   - Nikto (web scanner)
   - Python packages (colorama, requests, folium, plotly, reportlab)
6. Launch DSTerminal from Start Menu or Desktop shortcut

# Installation path
%APPDATA%\DSTerminal\
%APPDATA%\DSTerminal_Workspace\

# Silent installation
DSTerminal_Installer_2026_v3.1.13.exe /VERYSILENT /SUPPRESSMSGBOXES

3.2 Linux Installation

# Clone the DSTerminal repository
git clone https://github.com/Stark-Expo-Tech-Exchange/DSTerminal_releases_latest.git
cd DSTerminal_releases_latest

# Install Python dependencies
pip install -r requirements.txt

# Optional: Install additional tools
sudo apt update
sudo apt install nmap sqlmap nikto

# Run DSTerminal
python dsterminal.py

3.3 macOS Installation

# Install using Homebrew
brew install nmap sqlmap nikto

# From source
git clone https://github.com/Stark-Expo-Tech-Exchange/DSTerminal_releases_latest.git
cd DSTerminal_releases_latest
pip3 install -r requirements.txt
python3 dsterminal.py
