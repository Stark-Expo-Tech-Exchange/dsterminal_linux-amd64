DSTERMINAL CONSOLE v1.0.0
========================================

This is the portable console version of DSTERMINAL.

HOW TO USE:
1. Double-click launch_dsterminal.bat (or DSTerminal.exe directly)
2. Type commands at the console prompt
3. Type 'help' for available commands
4. Type 'exit' to quit

SYSTEM REQUIREMENTS:
- Windows 10 or later
- 2GB RAM recommended
- 100MB free disk space

FEATURES:
- Console-based interface
- Command-line operations
- Fast and lightweight
- No browser required

NOTES:
- No installation required
- No admin privileges needed
- Settings saved locally

TROUBLESHOOTING:
- If the console doesn't start, check if any antivirus is blocking it
- Try running as administrator for full features
